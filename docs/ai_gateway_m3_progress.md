# AI Gateway M3 开发进度（2026-11-21）

M2 的 PR #3 与 M3 前两段的 PR #4 已合并到 `main`。本段继续实现每次物理模型调用的独立计量与费用账本。

- 已设计：价格版本与供应商 token 用量分开保存；缺失上报保持 `NULL`，缓存输入从总输入中扣除后按专属费率计算；使用 `Decimal`，不使用浮点货币。
- 已实现：纯领域 `TokenUsage`、`PriceVersion` 和 `calculate_cost`；价格版本、物理调用与用量回执 ORM 和正式 SQL 迁移。调用起点固定价格版本；调用登记、CAS 终态、只插入回执及同键幂等冲突检查已实现。数据库触发器禁止历史价格与回执更新/删除。Run 汇总按调用只选最新已确认回执，按币种分别计费。OpenAI SDK 使用计量 HTTP 客户端，每次实际发送在请求前独立登记；结束时保存传输状态与未知用量。若该次 JSON 或 SSE 响应含供应商用量，追加独立回执并按调用起点价格计算费用。内部失联核对只处理超过 Run 截止时间与宽限期的调用，标为未知并阻断自动续跑；迟到传输证据和费用仍可追加。缺少 M3 迁移时 API 拒绝启动。
- 已验证：Python 3.12 本地领域、表约束、存储、传输与 `/api/chat` 回归通过；一次性 PostgreSQL 18 容器专项覆盖重复迁移、未知费用 NULL、Decimal 金额、迟到回执、账本不可变约束，以及同步和异步模拟 HTTP 请求写入。SDK 实际 429 重试测试确认两次发送产生两个不同 call_id；JSON 与 SSE 分块解析、供应商用量入账及金额在本地和一次性 PostgreSQL 中通过。失联核对的截止时间边界、Run 阻断、同步和异步迟到回执在本地与 PostgreSQL 中通过。PR #5 上次远端 CI run `44876607983` 成功；本次恢复提交的 CI 待推送后核对。
